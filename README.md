# velo_roads_analysis
Data Analysis of velo roads and parkings in Baku based on open data. Found the longest velo road, identified "lonely" parkings and out-of-city parkings. Gave strategic recommendations based on data.
Datasets:
•	Velo Roads - https://opendata.az/@azerbaycan-yerustu-neqliyyat-agentliyi/velosiped-zolaqlarinin-cografi-koordinatlari
•	Velo Parkings - https://opendata.az/@azerbaycan-yerustu-neqliyyat-agentliyi/velosiped-parkinq-menteqelerinin-cografi-koordinatlari
